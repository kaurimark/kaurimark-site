# kaurimark.com

The source for Kauri Markkanen's personal website. It is a dependency-free static page built with HTML and CSS.

## Run locally

```sh
python3 -m http.server 4173 --directory public
```

Then open `http://localhost:4173`.

## Test

```sh
npm test
```

## Deploy

Deploy the `public` directory to the `kaurimark-site` Cloudflare Pages project.
